# Contributing to tpt-dynamics

Contributions are accepted **as issues only**. Please open an issue to report a
bug, request a feature, or propose a change. Pull requests are not accepted at
this time.

## What to include in an issue

* **Bug reports:** the crate and version (or commit), the Rust toolchain
  (`rustc --version`), the operating system, a minimal reproduction, what you
  expected, and what happened.
* **Feature requests:** the problem you are trying to solve, the proposed
  behaviour, and any relevant physics or data-format references (for example a
  CODATA value or a file-format specification).
* **Dependency suggestions:** the crate name, its licence, and whether it has any
  C/C++ or `*-sys` dependencies. Only MIT, BSD, Zlib, ISC, Unicode, or dual
  `MIT OR Apache-2.0` licences are acceptable; see `deny.toml`.
