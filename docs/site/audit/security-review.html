Security review: parser attack surface and resource limits

  • Date: 2026-11-16
  • Scope: untrusted-input readers in tpt-dynamics-data and tpt-dynamics-sim, plus the trajectory reader if present. Fuzz coverage is in tpt-dynamics-data/tests/fuzz_parsers.rs; see docs/fuzzing.md.
  • Method: code reading of each reader, a grep for allocations driven by file-declared lengths (Vec::with_capacity, vec![0; n], read_exact, take), and the randomised tests above.
  • Scope note: findings in files outside tpt-dynamics-data/src/{arrow_ipc,jagged}.rs are reported only. They were not modified.

Findings

IDSeverityLocationDescriptionRecommendation
S-1Medium (memory DoS)tpt-dynamics-sim/src/pdb.rs:49, gro.rs:45 (BufRead::lines)A single very long line (no newline) is read fully into memory before parsing. The CSV reader already caps this.Replace lines() with a bounded line reader (for example, the approach in csv.rs::read_line with a max_line_bytes). Owner: sim crate.
S-2Lowtpt-dynamics-sim/src/gro.rsThe atom count is parsed from text. The pre-allocation is capped, but the loop trusts the count until EOF.Acceptable. Optionally reject counts above a configured maximum.
S-3Lowtpt-dynamics-sim/src/config.rs::from_toml_strNo input size cap. The toml crate's depth handling was not verified in this review.Cap input length (for example, 1 MiB) before parsing.
S-4Infobindings/tpt-dynamics-pyunsafe is allowed for generated glue, and ADR-007 is referenced but does not exist.Write ADR-007 before release (see docs/audit/unsafe-audit.md).
S-5Infotpt-dynamics-data/src/columnar.rsCorrupt files can yield Truncated or ChecksumMismatch only after reading the column. Memory is bounded by the file, so this is not a vulnerability.None.
S-6InfoTrajectory readerNot on master at review time.Apply the same rules: length checks against remaining bytes, caps on counts and line lengths, and fuzz tests before merge.

Fixes made

None in existing files. The new files arrow_ipc.rs and jagged.rs were written with the limits above. Findings S-1 to S-3 belong to the sim crate and are reported only, as the scope required.

Verification

  • cargo test -p tpt-dynamics-data --test fuzz_parsers passes with the default iteration count, and with FUZZ_ITERS set higher (see docs/fuzzing.md).
  • The truncation tests check every prefix of a valid input for the columnar and Arrow-IPC readers. The serialise tests do the same for each histogram type.
