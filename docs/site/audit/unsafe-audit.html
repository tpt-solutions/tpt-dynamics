Unsafe-code audit

  • Date: 2026-11-16
  • Scope: every .rs and .toml file in the workspace, excluding target/ and .git/. Searched with rg -w unsafe.
  • Policy: ADR-006. Every crate forbids unsafe_code. An exception needs an ADR, a local #[allow(unsafe_code)], and a // SAFETY: comment.

Result

No unsafe block, unsafe fn, unsafe impl or unsafe trait exists in hand-written code. The only matches are documentation comments and lint configuration.
