Migrating from PyROOT to tpt_dynamics

This page maps common PyROOT idioms to their tpt_dynamics equivalents. The examples are the kind of analysis code that is typical of ROOT-based HEP work. Every tpt_dynamics call shown here is covered by the test suite in bindings/tpt-dynamics-py/tests/test_basic.py.

Example 1: a filled histogram with errors

PyROOT:

import ROOT
h = ROOT.TH1F("mll", "m_ll;m [GeV];events", 60, 60.0, 120.0)
for m in masses:
    h.Fill(m)
for i in range(1, h.GetNbinsX() + 1):
    c, e = h.GetBinContent(i), h.GetBinError(i)
    print(h.GetBinCenter(i), c, e)

tpt_dynamics:

import numpy as np
import tpt_dynamics as td

h = td.Histogram1D(60, 60.0, 120.0)   # ROOT bins 1..60 are 0..59 here
h.fill(np.asarray(masses))
centers = h.bin_centers()
for c, content, err in zip(centers, h.contents(), h.errors()):
    print(c, content, err)

Note the index base: ROOT GetBinContent(1) is the first bin, and tpt_dynamics uses zero-based indices. Histograms here have no ROOT-style "bin 0 is underflow" convention; underflow and overflow are separate properties.

Example 2: summing histograms from several files (hadd)

PyROOT:

total = ROOT.TH1F("total", "", 50, 0, 200)
for name in ["run1.root", "run2.root"]:
    f = ROOT.TFile.Open(name)
    total.Add(f.Get("pt"))

tpt_dynamics: histograms are built per worker, then merged in memory. Histograms are not yet written to or read from files from Python; if you need to pass them between processes, send to_dict() output.

import numpy as np
import tpt_dynamics as td

parts = []
for chunk in chunks:                       # each chunk is a numpy array
    h = td.Histogram1D(50, 0.0, 200.0)
    h.fill(chunk)
    parts.append(h)

total = td.Histogram1D(50, 0.0, 200.0)
for p in parts:
    total.merge(p)

Example 3: a selection on a tree-like dataset

PyROOT:

tree.Draw("pt >> h(50, 0, 200)", "pt > 20 && abs(eta) < 2.5 && njets >= 2")

tpt_dynamics:

import numpy as np
import tpt_dynamics as td
from tpt_dynamics import col

data = {
    "pt": pt,           # numpy float64
    "eta": eta,         # numpy float64
    "njets": njets,     # numpy int64
}
sel = (col("pt") > 20.0) & (col("eta").ge(-2.5)) & (col("eta").le(2.5)) & (col("njets") >= 2)

selected = td.LazyFrame.scan_dict(data).filter(sel).collect()

h = td.Histogram1D(50, 0.0, 200.0)
h.fill(selected["pt"])

abs(eta) < 2.5 is written as two bounds, because the expression language has no abs yet. Only the expression functions listed in the reference (invariant_mass, delta_r, transverse_momentum) are available as built-ins.

Example 4: a 2D distribution with its projections

PyROOT:

h2 = ROOT.TH2F("eta_phi", "", 40, -2.5, 2.5, 32, -3.2, 3.2)
for e, p in zip(eta, phi):
    h2.Fill(e, p)
proj = h2.ProjectionX("px")

tpt_dynamics:

h2 = td.Histogram2D(40, -2.5, 2.5, 32, -3.2, 3.2)
h2.fill(eta, phi)
proj = h2.project_x()
grid = h2.contents()        # shape (40, 32)

Plotting

tpt_dynamics has no Draw(). Plot the arrays with matplotlib:

import matplotlib.pyplot as plt

h = td.Histogram1D(50, 0.0, 200.0)
h.fill(pt)
plt.stairs(h.contents(), h.edges(), fill=False)
plt.errorbar(h.bin_centers(), h.contents(), yerr=h.errors(), fmt="none")
plt.xlabel("pT [GeV]")
plt.ylabel("events")

Simulation (no ROOT equivalent)

run_simulation runs a molecular dynamics simulation from a TOML string and returns energies as numpy arrays. See the package README for an example.
